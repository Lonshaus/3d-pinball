# 3D 彈珠台

用 Three.js + TypeScript + Vite 製作的立體彈珠台，支援電腦、手機與平板。

## 開發

```bash
npm install
npm run dev      # 開發伺服器（--host，同網段手機也能連）
npm run build    # 型別檢查 + 打包到 dist/
npm run preview  # 預覽打包結果
```

## 操作

| 動作 | 電腦 | 手機 / 平板 |
|---|---|---|
| 左擋板 | `Z` / `←` / 左 Shift | 點螢幕左半邊 |
| 右擋板 | `/` / `→` / 右 Shift | 點螢幕右半邊 |
| 發射 | 按住空白鍵蓄力，放開發射 | 按住右下角按鈕 |
| 搖台 | `X` 左 / `C` 上 / `N` 右 | — |
| 暫停 | `Esc` / `P` | 右上角按鈕 |

## 關卡

六個關卡一開始就全部開放，可以任選。每一關有自己的元件配置、配色、燈光、背景粒子與音效音高。

| # | 關卡 | 風格 | 配置重點 | 目標分數 |
|---|---|---|---|---|
| 1 | 霓虹都市 | 合成波霓虹、夕陽與城市剪影 | 3 個彈射柱、左側落靶、右側環道 | 20,000 |
| 2 | 深海秘境 | 海底光影、珊瑚、上升氣泡 | 4 個彈射柱、雙側落靶、頂部獎勵洞 | 30,000 |
| 3 | 熔岩火山 | 發光熔岩裂縫、飄散火星 | 4 個彈射柱、兩組落靶、雙獎勵洞 | 45,000 |
| 4 | 台灣夜市 | 紅燈籠、攤販霓虹招牌 | 燈籠彈射柱群、射氣球落靶、夾娃娃獎勵洞 | 35,000 |
| 5 | 糖果樂園 | 明亮粉彩、棒棒糖、糖粒 | 5 個軟糖彈射柱、雙側落靶 | 40,000 |
| 6 | 星際太空 | 星雲、環狀行星、螺旋星系 | 大小不一的行星彈射柱、雙黑洞獎勵洞、環道 | 50,000 |

最高分會存在瀏覽器裡。

## 架構

```
src/
├─ physics/world.ts     # 專用 2D 彈珠物理（膠囊碰撞、擋板、600Hz 子步）
├─ table/layout.ts      # 檯面幾何與元件配置（純邏輯，可在 Node 測試）
├─ levels/levels.ts     # 關卡與主題設定
├─ game/game.ts         # 規則：計分、倍率、救球、搖台、關卡狀態
├─ render/              # Three.js 場景、檯面模型、程序化貼圖、特效
├─ input/input.ts       # 鍵盤與觸控
├─ audio/sfx.ts         # Web Audio 合成音效
└─ main.ts              # 介面與主迴圈
```

物理在檯面平面上以 2D 計算，畫面以 3D 呈現（檯面傾斜 6.5°）。
